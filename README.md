COLOR SEPARATOR CONVEYOR

PROJECT OBJECTIVE: Within a manufacturing facility, motor color will be utilized as the primary criterion to segregate motors destined for domestic versus international distribution. Motors allocated for export (metallic) require supplementary processing, while single-phase motors (blue) have been specified to necessitate additional wiring. Conversely, green motors are designated as prototypes and are to be palletized for storage. This project encompasses the comprehensive system design and PLC programming tailored to execute these precise operational requirements.

OPERATIONAL WORKFLOW:

    A retroreflective sensor detects the presence of an object, thereby initializing the primary conveyor's movement.

    As the object advances along the belt, one of three specialized sensors identifies its specific color profile and actuates the corresponding sorting pusher.

    The actuation of the pusher transfers the motor onto the adjacent cross-conveyor.

    Upon successful transfer to the secondary belt, a diffuse sensor registers the object, subsequently triggering the operation of that specific conveyor.
